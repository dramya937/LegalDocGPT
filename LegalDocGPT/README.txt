LegalDoc GPT: AI-Powered Contract Analysis

Description:
This tool uses OpenAI's GPT to analyze legal contracts. It extracts key clauses, flags risks, 
and summarizes the contract in plain language for non-experts.

Usage:
1. Install dependencies: pip install -r requirements.txt
2. Set your OpenAI API key in clause_analyzer.py and summarizer.py
3. Run main.py and provide the path to a PDF or DOCX contract
4. Get a summary with key clauses and risk levels

Dependencies:
- Python 3.8+
- openai
- PyPDF2
- python-docx
